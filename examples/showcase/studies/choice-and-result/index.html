TAKE THE RELATIONSHIP, NOT THE SKIN

Keep identity close.
Let the form change.

A useful choice explains both “which one?” and “what changed?” The control alone cannot do all of that work.

01

When it earns the space

A small, mutually exclusive set with useful differences. Visible labels and descriptions support comparison; a nearby result makes the consequence inspectable.

02

Where it starts to strain

Long descriptions increase the distance between choices. A large set demands scrolling. On a phone, a result after the full list can disappear from the working position.

03

What the alternative costs

A menu keeps a long set compact, but hides alternatives until opened and weakens side-by-side comparison. If people need several choices, use a multi-select pattern; if they need an exact quantity, use a numeric control.

Follow the mechanism in the source+

One selected ID drives every output. Changing language translates that same record; it does not choose another one. Short and long copy are authored variants. Reloading resets this study.
