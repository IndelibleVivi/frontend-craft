Step 02 / 03第 02 / 03 步

The change改动

Hover-only help failed the condition, so the change spells the essential help out inside the toolbar row itself. The toolbar keeps the same three actions; nothing was added to the note editor's feature set. The left picture is a labelled illustration. The working editor shows the change; use its controls to try it.

只靠悬停的帮助不满足条件，所以改动把必要的提示直接写进工具栏这一行。 工具栏仍然只有同样的三个操作，笔记编辑器的功能没有增加。 左侧是标注清楚的示意图，可操作的编辑器展示了这次改动，可以直接试用。
